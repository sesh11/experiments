# Hello World

A minimal HTTP "Hello, World!" app using only the Python standard library (Python 3.8+).

## Run

```bash
python3 hello_world/app.py
```

Then open http://127.0.0.1:8000 or run:

```bash
curl http://127.0.0.1:8000
# Hello, World!
```

Set `PORT` to use a different port, e.g. `PORT=9000 python3 hello_world/app.py`.
